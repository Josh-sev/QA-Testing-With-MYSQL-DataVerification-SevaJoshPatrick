# Kara David's Wish Note: QAT Toolkit

## Repository Overview

This QAT toolkit / repository contains three parts:

- **Part A:** This `readme.md` file, containing the test case for an AI-generated web application.
- **Part B:** The AI prompt used to create the test web application, named `webapp-generation-prompt.txt`.
- **Part C:** The single-file PHP web application generated by AI, `test-webapp.php`.

> The original test case source text is kept in the file `textcase.txt`.

## Test Case Documentation

| Field | Details |
|---|---|
| **Test Case ID** | TC-DataEntry-001 |
| **Test Case Title** | Data Entry - Valid |
| **Description** | Functional testing of the Data Entry page with backend validation using MySQL queries. |
| **Preconditions** | Kara David Birthday Wishnote App is installed locally and the MySQL database is pre-populated for comparison. The Data Entry page is accessed in the latest Chrome/Firefox browser. |
